# ADR 0001: Phase 0 采用确定性纵向切片

- 状态：已接受
- 日期：2026-09-24

## 背景

OpsPilot 最终需要接入模型、监控、日志、CMDB、Runbook、审批和沙箱执行。若在首阶段同时连接真实系统，接口错误、模型随机性和基础设施问题会互相干扰，难以验证 Agent 的控制流和安全边界。

## 决策

Phase 0 使用 FastAPI、React、PostgreSQL、Redis 和显式状态机完成一条端到端纵向切片。模型与五个只读工具使用确定性 Mock 数据，但共享未来真实适配器所需的 Schema 和 Tool Gateway。每次诊断都持久化状态转换、工具调用、证据 ID 与最终结论。

数据库结构由 Alembic 迁移管理；Docker Compose 是本地集成环境；本地与 CI 同时执行 lint、类型检查、单元测试、集成测试和前端构建。

## 后果

- 优点：无需 GPU 即可复现；测试稳定；能尽早发现 API、数据库、容器和前端契约问题。
- 代价：Phase 0 的诊断质量不代表真实模型效果，Mock 指标不能用于性能宣传。
- 约束：后续真实适配器必须通过相同 Schema 和 Tool Gateway，不能绕过状态机、审计与审批边界。
